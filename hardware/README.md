# Hardware / CAD

The complete printable 3D model is distributed separately through Cults3D:

**[SCARA Robot Arm — complete 3D design](https://cults3d.com/en/3d-model/gadget/scara-robot-arm-alsaadi)**

This GitHub repository keeps the engineering documentation, firmware reference, design images, and supporting technical material together without duplicating the complete downloadable model package.

## Local folder organization

```text
hardware/
├── cad/
│   ├── STEP/
│   └── SolidWorks/
└── stl/
```

These folders can be used later for selected CAD/STL files if a separate GitHub release is desired.
