# SCARA Robot Arm

![SCARA Robot Arm](media/cad/scara-assembled-perspective.jpg)

Custom **4-axis SCARA robotic arm** developed as a mechatronics graduation project. The system combines mechanical design, 3D-printed structures, belt transmissions, ESP32-based embedded control, stepper-motor actuation, forward/inverse kinematics, homing, calibration, a servo gripper, and browser-based operation.

## Full 3D model

The complete printable 3D design is distributed through Cults3D:

**[Download / view the complete SCARA Robot Arm 3D model on Cults3D](https://cults3d.com/en/3d-model/gadget/scara-robot-arm-alsaadi)**

The GitHub repository focuses on engineering documentation, firmware reference material, images, and system architecture. Refer to the Cults3D page for the complete downloadable 3D model package and its distribution terms.

## Project overview

The robot was designed as a complete electromechanical subsystem rather than only a CAD model. The SCARA structure uses a vertical Z-axis, two rotational arm links, and a servo gripper. An ESP32 provides motion control and the browser interface, while DRV8825 modules drive the NEMA 17 stepper motors.

| Item | Specification |
|---|---|
| Robot type | 4-axis SCARA robotic arm |
| Vertical Z stroke | 290 mm |
| Fixed base offset | L1 = 205 mm |
| Rotational links | L2 = 222 mm, L3 = 156.8 mm |
| Maximum reach | approximately 584 mm |
| Main actuators | NEMA 17 stepper motors |
| Motor drivers | DRV8825 |
| Main controller | ESP32 |
| End effector | MG90S servo gripper |
| Transmission | GT2 timing belts and pulley reductions |
| Vertical guidance | Lead screw + two 10 mm steel shafts + LM10UU bearings |
| Homing | Limit switches |

## Mechanical design

### Z-axis

The Z-axis separates **lifting** from **structural support**. An 8 mm lead screw provides vertical actuation, while two 10 mm steel linear shafts and LM10UU bearings carry the bending loads generated by the extended arm.

![Z-axis mechanism](media/mechanical/z-axis-components.png)

### L1 → L2 transmission

The first rotary transmission uses a two-stage GT2 belt reduction. A 400 mm belt drives a compound 23/80-tooth pulley, followed by a 300 mm belt driving a 92-tooth joint pulley. The arrangement increases torque and angular resolution while avoiding the backlash of a long printed gear train.

![L1 to L2 belt transmission](media/mechanical/l1-l2-belt-transmission.png)

### L2 → L3 transmission

Motor 3 is positioned near Joint 2 rather than at the arm tip to reduce moving inertia. A 400 mm GT2 belt transfers motion to a 90-tooth pulley at Joint 3.

![L2 to L3 belt transmission](media/mechanical/l2-l3-belt-transmission.png)

### Joint bearing arrangement

The primary rotary joints use thrust bearings to carry axial load and a radial ball bearing to maintain shaft alignment. This prevents the stepper motor shafts from directly supporting the weight of the arm.

## Electronics

The system uses separate motor and logic voltage rails. The 12 V supply feeds the stepper motor drivers, while a buck converter provides regulated low-voltage power for the control electronics and gripper servo.

![SCARA electronics wiring diagram](media/electronics/electronics-wiring-diagram.jpg)

Main hardware:

- ESP32 microcontroller
- 3 × NEMA 17 stepper motors
- 3 × DRV8825 stepper drivers
- MG90S servo gripper
- 3 × limit switches
- 12 V switched-mode power supply
- 5 V buck converter
- 100 µF capacitors at the stepper-driver power inputs

## Software and control

The project software architecture includes:

- Joint-space motion control
- Speed and acceleration control
- Forward kinematics (FK)
- Inverse kinematics (IK)
- Cartesian control
- Homing and calibration
- Position monitoring
- Servo gripper control
- Browser-based user interface
- Recipe / saved-operation concepts
- Persistent configuration storage
- HTTP communication
- Architecture prepared for wider robotic-cell integration

## Firmware note

`firmware/legacy-v10/` is preserved as a development snapshot demonstrating ESP32 motion control, homing, FK/IK, calibration, and web-control implementation.

Its mechanical constants do **not** represent every final dimension documented in the completed mechanical design. Recalibration and verification are mandatory before using it on physical hardware.

## Safety

This is an experimental robotic system. Before energizing the robot, verify joint limits, step direction, homing direction, driver current limits, gripper clearance, emergency-stop behavior, and power wiring. Keep immediate access to motor power during commissioning.
